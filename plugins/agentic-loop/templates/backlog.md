# Loop backlog — known, unfixed, cross-loop

**Read this before choosing the next loop's theme. Append to it before finishing
a loop.** A single session only knows what it just did; this file is the only
thing that remembers what earlier loops found and never fixed.

Rules:

- One line per item, plus provenance: which loop found it, and whether it was
  **verified** or **suspected**. Don't record guesses as facts.
- Remove an item only when it's actually fixed and shipped — not when a loop
  decides it's low priority. Downgrade it instead.
- Items a **human** must do go in their own section. Agents cannot clear those,
  and a brief that ignores them wastes a loop.
